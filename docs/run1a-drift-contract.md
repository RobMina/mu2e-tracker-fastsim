# Run 1A drift/timing contract and stock-oracle build

This is the boundary between the measured-wire initializer and a physical drift fit. The wire-only
refit does **not** consume the existing phi-zero drift table or assign TOT-derived drift radii.

## Stock semantics to preserve

The pinned stock implementation is in Offline `TrackerConditions/src/{StrawDrift,StrawResponse}.cc`
and `Mu2eKinKal/{inc/KKStrawHit.hh,src/KKFitUtilities.cc}`. The actual sparse area's backing headers
were checked against the APIs used by the new oracle. The user-built plugin now passes the saved-event
runtime check below. The pinned backing sources, not a potentially different live Offline checkout,
are the reference for the evaluator.

- `ComboHit::time()` is the calibrated early-end time, already PBT-subtracted. Dumper `s_time` is
  `correctedTime()`, which also subtracts measured propagation and the TOT drift estimate. For the
  physical measurement use `s_et0/s_et1` selected by `s_eend`, **not** `s_time`.
- `hitLine` passes early then late endpoints, but `SensorLine` constructs `lineseg_(late,early)`:
  its **direction is late to early**, toward the measured signal. The speed is
  `2*halfPropV(sid,1000*energyDep_MeV)`. With `s=unit(early-late)`, sensor-POCA time is
  `t_early-dot(early-sensorPOCA,s)/speed`. Evaluate propagation from the **fitted sensor POCA**,
  not from the fixed measured longitudinal estimate; early/mid/late positions have times
  `t_early`, `t_early-L/(2*speed)`, `t_early-L/speed`, respectively.
- Fitted drift delta-t is sensor-POCA time minus particle-POCA time. The particle time contains
  fitted t0 and signed flight time at beta*c. Do not subtract PBT twice or replace delta-t by TOT.
- With `q=particlePOCA-sensorPOCA`, sensor unit direction `s` and nominal trajectory field unit `b`,
  stock forms `r=s cross b`, reverses r if `r dot q<0`, then computes `atan2(q dot r,q dot b)` and
  folds above pi/2. **Do not normalize s cross b**: that changes tilted-wire results. This angle is
  neither track azimuth nor track/wire crossing angle. The trajectory field is distinct from the
  detector-origin Bz used to construct the global drift model.

`StrawResponse::driftInfo` currently ignores its straw ID and applies:

1. Use phi=0 only if configured `driftIgnorePhi`; otherwise retain the supplied angle.
2. Raw `cDrift = StrawDrift::T2D(dt,phi,false)`. This is nonlinear even when `useNonLinearDrift`
   changes the behavior of the separate response D2T/T2D convenience methods.
3. Fit the offset calibration's local up-to-five-bin linear regression at cDrift. Subtract its
   value to get rDrift. This is not piecewise interpolation between calibration knots.
4. `driftVelocity = GetInstantSpeedFromD(cDrift)*(1-offset_slope)*dRdTScale`. It is not a numerical
   derivative of an interpolated calibrated-radius table.
5. Evaluate signed and unsigned error calibrations by the same local regression at rDrift.

Negative dt and tails **extrapolate**: clamp interval indices, not input values. Calibrated radius
and errors are not automatically clipped to a straw radius. Native T2D time nodes stop at
`(ceil(max_time/deltaT)-1)*deltaT`, and distance nodes are generated by repeated addition below the
nominal straw outer radius. Maker T2D inversion/indexing is part of the contract; a nicer inverse
is not necessarily equivalent. T2D folded phi is double, whereas D2T folded phi is float.

A final-output bilinear `driftInfo` table cannot reproduce this composition exactly. The options
are native model arrays plus calibration arrays (requiring Offline accessors), or an explicit
source-level port from resolved FHiCL, nominal radii and exact origin Bz, validated against stock.
`reco.fielddrift` implements the latter, leaving shared digitiser code and Offline classes unchanged.
It passes the stock-response comparison below; it is not yet integrated into a physical track fit.
The existing five-significant-digit B-field CSV is not adequate provenance for exact maker closure.

## Stock oracle: built and run on saved events

`art/TrkFastSim/src/FieldOnDriftOracle_module.cc` queries the public stock `driftInfo` API. It is a
separate opt-in analyzer; legacy `StrawHitTableDumper` and all reconstruction defaults are untouched.
`run1a_drift_oracle.fcl` schedules only this analyzer on saved events, with no hit reconstruction,
transport, digitisation, track fit or art output. One event suffices for values; a small multi-event
run exercises the first-IOV guard.

The default query domain is **validation only**, not a reconstruction delta-t cut:
- rectangular -50..200 ns in 0.05 ns intervals and 77 angles including 0 and pi/2;
- 8192 deterministic off-grid queries, including negative and wrapped angles;
- paired explicit time/angle probes, configurable for bin-transition checks;
- hard limit 1M queries, with failure rather than truncation.

The tree records `cDrift`, `rDrift`, stock velocity, signed/unsigned errors, input/used phi, first
event/straw ID, response/tracker CIDs and their IOV intersection. It exports full-precision field
vector and detector-origin coordinates, float-rounded origin Bz, stock CC and nominal geometry
radii. It fails on missing field coverage, nonfinite values or later events outside that intersection.
It does not claim multi-IOV support, per-straw drift calibration or field-map tracking equivalence.

The runner `scripts/run1a_drift_oracle_export.sh AREA DIG_ART NEWOUT [COUNT=10]` saves expanded FHiCL,
backing path and SHA256 hashes of the oracle and pinned drift sources; logs/output go in NEWOUT.
It has no build command. The user completed the full build on 2026-11-06; the plugin timestamp
07:58:01 CST is newer than source 06:49:48. Muse's completion record ends 07:58:01, and all dynamic
libraries resolve to the expected p110 area/backing. No build pane was available to inspect.

Both the 1-event smoke and 10-event repeat on saved `g4-full/dig.art` exited 0. Each contains one
first-IOV oracle row with **393276 finite queries** (385077 rectangular, 8192 off-grid, 7 explicit).
The 10-event log reports 10/10 successful oracle calls; all exported fields are **array-exact**
between runs. This tests same-IOV reuse, not an out-of-IOV rejection or multi-IOV support.
`validation.run1a_drift` checks configured coordinates, complete census, finite payload, geometry,
field rounding, IOV containment, analyzer-only scheduling, source/config hashes and exact repeats.

Measured conditions: detector origin **(-3904,0,10171) mm**, field vector

## Source-level evaluator validation

`build_model(drift_cfg, response_cfg, *, wire_radius, outer_radius, bz)` constructs bounded native
arrays; `drift_info(model, dt, phi)` is fully vectorized with scalar/empty/broadcast support.
It preserves repeated-addition radii, float Bz/CC, the maker's **upper-index** inverse and GSL's
local-regression arithmetic. Query values are never clipped; unsafe/nonfinite arithmetic raises.
No oracle response value enters model construction. Existing digitiser and wire-fit code are unchanged.

All **393276** stock queries pass thresholds fixed before comparison:

| Quantity | Maximum absolute difference | Threshold |
|---|---:|---:|
| Raw cDrift (mm) | 1.3785e-12 | 1e-10 |
| Calibrated rDrift (mm) | 6.8390e-14 | 1e-10 |
| Drift velocity (mm/ns) | 1.2559e-15 | 1e-10 |
| Signed/unsigned errors (mm) | 0 / 0 | 1e-12 |
| Used phi / public CC | exact / exact | exact |

This is numerical agreement with pinned stock, not cross-platform bitwise identity. The tested
oracle domain is -50..200 ns, including wrapped angles; wider extrapolation has synthetic tests,
not a larger real-stock validation domain. The stock errors are constant in this configuration;
nonconstant errors and calibration-bin switches are covered by independent scalar tests.

The audit now requires successful log/completion/manifest sidecars, validates source filenames and
hex digests, integer metadata, and caps ROOT file/basket size before array deserialization. It records
source digests rather than claiming a cryptographic ROOT/log/loaded-binary binding. Read-only review
prompted these guards. No sidecars are optional for a CLI pass.

Validation: **78 model + 57 audit tests**; the focused run including existing helix, wirefit,
association, hit-reco and shared-drift tests gives **488 passes** with warnings treated as errors.
Read-only model review found no blocker. The earlier affected suite's 766 passes remains separate
historical evidence, not a new full-suite/CI run. Final report: `drift-model-check-20261106-final`.
